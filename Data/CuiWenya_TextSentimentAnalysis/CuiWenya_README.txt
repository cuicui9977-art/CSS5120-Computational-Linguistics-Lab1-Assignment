2. Dataset Introduction
2.1 Data Content & Characteristics
This dataset consists of 3799 short text samples with sentiment labels, structured into two core columns:
text column: Contains short-form text extracted from social media posts (primarily tweets), with lengths ranging from 10 to 60 characters. The content covers daily opinions, product feedback, and event comments, reflecting real-world informal language usage.
label column: Includes three sentiment categories—positive (e.g., "This movie was amazing, highly recommended!"), negative (e.g., "The service here was terrible and slow."), and neutral (e.g., "The meeting will start at 3 PM tomorrow."). The label distribution is balanced, with no significant bias toward any single category, making it suitable for baseline sentiment analysis model training.
2.2 Data Acquisition Method
The data was obtained from the Kaggle platform’s public Dataset.
2.3 Planned Research Uses
Explore the correlation between text length, lexical richness (e.g., number of emotional words), and sentiment polarity to identify key linguistic features that influence sentiment recognition.
Evaluate the impact of text preprocessing steps (e.g., stopword removal, emoji conversion, lowercase normalization) on model performance, providing insights for optimizing sentiment analysis pipelines.
